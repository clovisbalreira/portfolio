# GTA VI Landing Page

Landing page promocional inspirada no universo de Grand Theft Auto VI, desenvolvida com foco em interfaces cinematográficas, animações de scroll e storytelling visual.

## Visão geral

Este projeto simula uma campanha de divulgação de jogo, com ênfase em:

- hero section com vídeo em background
- animação de entrada e scroll com GSAP
- menu com estado visual alterado conforme rolagem
- layout responsivo
- identidade visual premium, alinhada ao estilo de marketing de jogos AAA

## Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- GSAP
- ScrollTrigger
- Google Fonts

## Requisitos

- Navegador moderno
- Acesso à internet para carregamento de fontes e scripts externos

## Funcionalidades implementadas

- `IntersectionObserver` para revelar seções conforme a página é percorrida
- `ScrollTrigger` para sincronizar animações com o scroll
- controle de tempo do vídeo da capa com base no movimento da página
- menu com comportamento dinâmico ao rolar a janela
- layout construído com estrutura semântica em HTML e estilos em CSS modularizado

## Observações técnicas

O projeto foi desenvolvido como estudo de front-end e experiência de usuário, com aplicação de técnicas de animação e storytelling visual em páginas promocionais. A implementação prioriza estética cinematográfica, sem depender de frameworks ou bibliotecas pesadas.
