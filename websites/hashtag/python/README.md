# 🐍 Python Hashtag - Coleção de Projetos Web

Coleção de aplicações web educacionais desenvolvidas com **Python e PyScript**, executando 100% no navegador. Cada projeto demonstra diferentes áreas de desenvolvimento com Python: automação, análise de dados, machine learning e inteligência artificial.

## 📚 Projetos Inclusos

### 1. 🤖 [Automação - Cadastro Automático de Produtos](./automacao/)
Aplicação para automação de cadastro de produtos em lote, processando dados de forma rápida e eficiente.

**Funcionalidades:**
- Importação de dados via CSV
- Validação automática de campos
- Processamento em lote com barra de progresso
- Relatório detalhado de sucesso/erro
- Interface intuitiva com feedback visual

**Tecnologias:** Pandas, HTML5, CSS3

---

### 2. 📊 [Análise de Dados - Análise de Cancelamentos](./analise-dados/)
Aplicação web para análise interativa de dados de cancelamentos, gerando visualizações e estatísticas.

**Funcionalidades:**
- Carregamento automático de dados do CSV
- Análise de padrões de cancelamento
- Visualizações interativas com Plotly
- Tabelas de resumo e estatísticas
- Interface escura e responsiva

**Tecnologias:** Pandas, NumPy, Plotly, HTML5, CSS3

---

### 3. 📈 [Previsão - Score de Crédito com IA](./previsao/)
Aplicação inteligente para análise e previsão de score de crédito utilizando machine learning.

**Funcionalidades:**
- Treinamento de modelo de machine learning
- Previsão de score de crédito para novos clientes
- Interface com formulário interativo
- Análise estatística de dados
- Visualização de resultados e confiança

**Tecnologias:** Pandas, NumPy, Scikit-learn, HTML5, CSS3

---

### 4. 💬 [ChatBot - Assistente de IA Conversacional](./chatbot/)
Chatbot inteligente que responde perguntas em tempo real através de integração com APIs de IA.

**Funcionalidades:**
- Interface de chat em tempo real
- Histórico de conversas visual
- Indicador de digitação do bot
- Validação de chave de API
- Design responsivo e acessível

**Tecnologias:** PyScript, APIs de IA, HTML5, CSS3

## 🎯 O que é PyScript?

**PyScript** permite executar Python diretamente no navegador, sem necessidade de servidor. Todos os cálculos e processamentos ocorrem localmente no seu computador.

**Benefícios:**
- ✅ Funciona 100% no navegador
- ✅ Sem necessidade de servidor
- ✅ Dados processados localmente (privacidade)
- ✅ Compatível com qualquer navegador moderno

## 💡 Dicas de Uso

1. **Sempre valide seus dados** antes de importar
2. **Faça backup** antes de processar em lote
3. **Use em modo privativo** para testar sem histórico
4. **Configure sua chave de API** antes de usar o ChatBot
5. **Verifique a internet** para carregar as bibliotecas

## 🔒 Privacidade e Segurança

- Todos os dados são processados **localmente no navegador**
- Nenhum dado é enviado para servidores externos
- Suas chaves de API permanecem sob seu controle
- Histórico de chats não é armazenado permanentemente

## 📝 Notas Importantes

- Os modelos de machine learning são treinados no navegador
- Use para análise indicativa, não como decisão final
- A precisão dos modelos depende da qualidade dos dados
- Processamento pode ser lento em conjuntos muito grandes
