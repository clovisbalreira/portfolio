# 📊 Análise de Cancelamentos

Aplicação web para análise interativa de dados de cancelamentos utilizando Python no navegador via PyScript.

## 🎯 Objetivo

Analisar padrões de cancelamentos em um conjunto de dados, gerando visualizações e estatísticas que ajudam na tomada de decisão.

## 🛠️ Tecnologias

- **PyScript** - Executa Python no navegador
- **Pandas** - Manipulação e análise de dados
- **NumPy** - Computação numérica
- **Plotly** - Visualizações interativas
- **HTML5 & CSS3** - Interface responsiva

## 📦 Arquivos

- `index.html` - Aplicação principal
- `cancelamentos.csv` - Dataset com dados de cancelamentos

## ✨ Funcionalidades

- Carregamento automático de dados do CSV
- Análise de padrões de cancelamento
- Visualizações interativas com Plotly
- Tabelas de resumo e estatísticas
- Interface escura e responsiva

## 📋 Requisitos

- Navegador moderno com suporte a JavaScript módulos
- Conexão com internet (para carregar bibliotecas externas)

## 💡 Notas

- A aplicação funciona 100% no navegador, sem necessidade de servidor
- Todos os dados são processados localmente
- Compatível com Chrome, Firefox, Safari e Edge
