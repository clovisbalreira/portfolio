# 🤖 Cadastro Automático de Produtos

Aplicação para automação de cadastro de produtos em lote, processando dados de forma rápida e eficiente utilizando Python no navegador.

## 🎯 Objetivo

Automatizar o processo de cadastro de produtos a partir de um arquivo CSV, oferecendo validação, processamento em lote e relatórios de status.

## 🛠️ Tecnologias

- **PyScript** - Executa Python no navegador
- **Pandas** - Processamento de dados em lote
- **HTML5 & CSS3** - Interface interativa

## 📦 Arquivos

- `index.html` - Aplicação principal
- `produtos.csv` - Dataset com dados de produtos

## ✨ Funcionalidades

- Importação de dados via CSV
- Validação automática de campos
- Processamento em lote com barra de progresso
- Relatório detalhado de sucesso/erro
- Interface intuitiva e responsiva
- Cores visuais para indicar status (OK/Aviso/Erro)

## 📋 Requisitos

- Navegador moderno com suporte a JavaScript módulos
- Arquivo CSV formatado corretamente
- Conexão com internet (para carregar bibliotecas externas)

## ⚠️ Avisos Importantes

- Sempre faça backup dos dados antes de processar
- Valide o arquivo CSV antes de importar
- Revise os dados carregados antes de confirmar

## 💡 Notas

- Processamento 100% no navegador
- Nenhum dado é enviado para servidores externos
- Compatível com Chrome, Firefox, Safari e Edge
