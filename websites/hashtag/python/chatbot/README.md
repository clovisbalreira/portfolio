# 🤖 ChatBot com IA

Chatbot inteligente executado 100% no navegador utilizando Python e integração com APIs de inteligência artificial.

## 🎯 Objetivo

Criar um assistente de IA conversacional que responde perguntas em tempo real através de uma interface web moderna e intuitiva.

## 🛠️ Tecnologias

- **PyScript** - Executa Python no navegador
- **API de IA** - Integração com modelos de linguagem
- **HTML5 & CSS3** - Interface conversacional moderna

## 📦 Arquivos

- `index.html` - Aplicação principal com interface do chatbot

## ✨ Funcionalidades

- Interface de chat em tempo real
- Histórico de conversas visual
- Suporte a múltiplas mensagens
- Indicador de digitação do bot
- Validação de chave de API
- Design responsivo e acessível
- Temas visuais otimizados

## 📋 Configuração

### Chave de API
- A chave de API deve ser configurada na interface antes de usar
- Será armazenada localmente no navegador (não é enviada para outros servidores)
- Diferentes provedores podem ser utilizados

### Requisitos
- Navegador moderno com suporte a JavaScript módulos
- Conexão com internet
- Chave de API válida do serviço de IA

## 💡 Notas

- Funciona 100% no navegador com PyScript
- Dados processados localmente
- Chave de API protegida e sob seu controle
- Compatível com Chrome, Firefox, Safari e Edge

## 🔒 Privacidade

- Suas conversas são processadas conforme a política do provedor de IA
- Nenhum dado é armazenado em nossos servidores
- Chave de API permanece local ao seu navegador
