Cadastro Automático de Produtos

Aplicação para automação de cadastro de produtos em lote, processando dados de forma rápida e eficiente utilizando Python no navegador.

Objetivo

Automatizar o processo de cadastro de produtos a partir de um arquivo CSV, oferecendo validação, processamento em lote e relatórios de status.

Análise de Cancelamentos

Aplicação web para análise interativa de dados de cancelamentos utilizando Python no navegador via PyScript.

Objetivo

Analisar padrões de cancelamentos em um conjunto de dados, gerando visualizações e estatísticas que ajudam na tomada de decisão.

Score de Crédito - Previsão com IA

Aplicação inteligente para análise e previsão de score de crédito utilizando machine learning, totalmente executada no navegador com Python.

Objetivo

Analisar dados de clientes e gerar previsões de score de crédito usando modelos de machine learning (scikit-learn), fornecendo insights para decisões financeiras.

ChatBot com IA

Chatbot inteligente executado 100% no navegador utilizando Python e integração com APIs de inteligência artificial.

Objetivo

Criar um assistente de IA conversacional que responde perguntas em tempo real através de uma interface web moderna e intuitiva.
