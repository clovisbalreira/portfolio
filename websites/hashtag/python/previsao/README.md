# 📈 Score de Crédito - Previsão com IA

Aplicação inteligente para análise e previsão de score de crédito utilizando machine learning, totalmente executada no navegador com Python.

## 🎯 Objetivo

Analisar dados de clientes e gerar previsões de score de crédito usando modelos de machine learning (scikit-learn), fornecendo insights para decisões financeiras.

## 🛠️ Tecnologias

- **PyScript** - Executa Python no navegador
- **Pandas** - Manipulação de dados
- **NumPy** - Computação numérica
- **Scikit-learn** - Machine learning e modelos preditivos
- **HTML5 & CSS3** - Interface interativa

## 📦 Arquivos

- `index.html` - Aplicação principal
- `clientes.csv` - Dataset de treinamento com dados de clientes
- `novos_clientes.csv` - Dataset para previsão

## ✨ Funcionalidades

- Carregamento automático de dados CSV
- Treinamento de modelo de machine learning
- Previsão de score de crédito para novos clientes
- Interface intuitiva com formulário
- Visualização de resultados e confiança
- Análise estatística de dados
- Suporte a múltiplas previsões

## 📊 Dados Utilizados

- **Dataset de Treinamento**: `clientes.csv` com histórico de clientes
- **Dataset de Previsão**: `novos_clientes.csv` com novos clientes para análise

## 📋 Requisitos

- Navegador moderno com suporte a JavaScript módulos
- Conexão com internet (para carregar bibliotecas externas)
- Arquivos CSV formatados corretamente

## ⚠️ Observações Importantes

- O modelo é treinado localmente no navegador
- Nenhum dado é enviado para servidores externos
- A precisão depende da qualidade dos dados de treinamento
- Use para análise indicativa, não como decisão final

## 💡 Processo

1. **Carregamento**: Importa dados dos CSV
2. **Preparação**: Processa e normaliza os dados
3. **Treinamento**: Treina o modelo com dados históricos
4. **Validação**: Avalia a precisão do modelo
5. **Previsão**: Realiza previsões para novos clientes

## 🔍 Interpretação dos Resultados

- **Score**: Valor entre 0 e 1 (quanto maior, melhor o score)
- **Confiança**: Nível de certeza da previsão
- **Fatores**: Principais variáveis que influenciaram a previsão
