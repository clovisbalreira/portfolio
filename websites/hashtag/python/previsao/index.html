🏦 Previsão de Score de Crédito (IA)

Conversão do notebook Jupyter (gabarito.ipynb) para PyScript — RandomForest vs KNN.

Carregando o ambiente Python no navegador (pandas, numpy, scikit-learn)… isso pode levar um pouco mais na primeira vez por causa do scikit-learn.

Passo 1 — Importar a base de dados

Lê o arquivo clientes.csv (~100 mil linhas). O download/leitura pode levar alguns segundos.

Passo 2 — Preparar a base para a IA

Codifica as colunas de texto (profissao, mix_credito, comportamento_pagamento) com LabelEncoder e separa os dados em treino (70%) e teste (30%).

Passo 3 — Treinar a Inteligência Artificial

Treina dois modelos: RandomForestClassifier (árvore de decisão) e KNeighborsClassifier (vizinhos próximos).

⚠️ Com ~70 mil linhas de treino, o navegador pode ficar sem responder por até 1 minuto durante o treino — isso é esperado, não feche a aba.

Passo 4 — Escolher o melhor modelo

Compara a acurácia dos dois modelos nos dados de teste e escolhe o melhor automaticamente.

Passo 5 — Prever novos clientes

Aplica o melhor modelo em novos_clientes.csv e mostra o score de crédito previsto para cada um.
