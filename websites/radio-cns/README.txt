# CNS Rádio — site
Site estático responsivo inspirado na experiência de web rádios modernas.

## Streaming
Configurado para:
https://s18.maxcast.com.br:8702/live

## Como publicar
Envie `index.html`, `style.css` e `script.js` para sua hospedagem (cPanel, Hostinger, Vercel, Netlify etc.).

## Observação
O player usa o stream diretamente no navegador. Para exibir automaticamente nome/capa da música, será necessário conectar uma fonte de metadados da Maxcast/Icecast que esteja disponível para acesso via navegador (CORS).
